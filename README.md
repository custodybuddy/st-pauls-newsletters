This repository contains St. Paul’s newsletter-related resources. For current reusable brand images, use the central [St. Paul’s Brand Assets](https://github.com/custodybuddy/st-pauls-newsletter-assets) repository.

## Shared Image Library

- [Selectable thumbnail gallery](st-pauls-image-library.html)

- [Canonical preset metadata](https://github.com/custodybuddy/st-pauls-newsletter-assets/blob/main/brand/assets/metadata/section-presets.json)

Image URLs for new templates must use existing files under `https://custodybuddy.github.io/st-pauls-newsletter-assets/brand/assets/`. Never guess filenames, reuse retired `/st-pauls-newsletter-assets/assets/` URLs, or assume `pending_review` images are approved. Keep past newsletters and approved editorial content intact.
